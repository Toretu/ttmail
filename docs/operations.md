# Operations Guide

## Daily tasks

- Review failed email sends.
- Review new replies.
- Process follow-ups due today.
- Review overdue follow-ups.
- Confirm campaign statistics.

## Campaign procedure

1. Review the target group.
2. Generate and inspect recipients.
3. Confirm unsubscribe and duplicate filtering.
4. Send a test email.
5. Obtain approval.
6. Send a controlled batch.
7. Review failures.
8. Continue batches as appropriate.
9. Process replies and follow-ups.
10. Close the campaign when complete.

## Administrative tasks

- Review inactive users and permissions.
- Review product prices and inventory.
- Review Microsoft Graph app registration and mailbox connection health.
- Review flow failures.
- Verify configuration changes are documented.

## Backup and recovery

Use encrypted MariaDB backups and approved server backup capabilities. Record the retention policy and recovery owner before production launch. Test restoration regularly.
